### Utilisation

Pour lancer le scraping entier du site

```bash
./projet.py
```
OU


```bash
./projet.py --categories all
```

Sinon pour lancer le scraping d'une ou plusieurs categories


```bash
./projet.py --categories nom_categorie ...
```

Pensez à bien mettre les majuscules aux noms des categories.
